# The 2 below remain open, and NOT for lack of a test written yet -- both
# are genuinely unreachable via any real transaction group, proven rather
# than merely asserted, so forcing a "passing" test for either would be a
# fabricated pass, not a real one:
#
#   N14 -- attest()'s pinned-tier check (a_version(pinned) == 1). The ONLY
#   writer of a pinned box is box.pin_write (contracts/state_anchor/box.py),
#   which always copies a ring record that JUST passed the "version != 0"
#   check (N12) -- and the ONLY value any ring write ever stores at the
#   version byte is the literal VERSION_1 constant from
#   record.build_record (ring boxes are zero-filled at ring_init_chunk, so
#   the only other possible value is 0, already excluded by N12). No ARC4
#   method in anchor_app.py writes any other byte to that offset --
#   revoke() only ever touches the flags byte (offset 1). A pinned record's
#   version is therefore always exactly 1 by construction, whenever it
#   exists at all; this defensive check cannot fire on any honestly- or
#   adversarially-constructed group.
#
#   N21 -- box.ring_admit_and_write's RING_WRITE_REGRESSION branch
#   (ex_block > new_block in the same ring residue slot). box.py's own
#   docstring already names this "unreachable via the honest path once
#   N-ADMIT holds (§5.4's distinctness lemma)" -- independently re-derived
#   this pass: N-ADMIT (checked earlier in the SAME call) requires
#   new_block + ring_n > hi_block, i.e. new_block > hi_block - ring_n. Any
#   record already occupying the slot (ex_block) was itself admitted at
#   some earlier hi_block' <= the current hi_block (hi_block is
#   monotonic non-decreasing), so ex_block <= hi_block. Combined:
#   ex_block - new_block < hi_block - (hi_block - ring_n) = ring_n. But a
#   same-residue collision requires ex_block - new_block to be a POSITIVE
#   MULTIPLE of ring_n (i.e. >= ring_n) -- a contradiction. No real group
#   can reach this branch with ex_block > new_block while N-ADMIT holds.
#
